## 术语记录方式

每个术语尽量按下面的结构记录：

- 名词：原文、常见中文说法、相关缩写。
- 一句话解释：先写能快速回忆的版本。
- 背景：这个词通常出现在哪类场景里。
- 例子：最好给出一个具体使用语境。
- 待确认：不确定的含义、来源或后续要查的资料。

## 新闻与趋势记录方式

每条新闻或技术更新先放进分类，再判断影响：

- 分类：AI 圈新闻、技术更新、社会热点、行业热点、经济热点。
- 事实：发生了什么，来源是否可靠。
- 机制：它改变了什么成本、效率、流程或需求。
- 影响：对个人技能、职业岗位、行业格局和宏观经济的影响。
- 行动：继续观察、立即试用、深入学习、记录案例或暂不跟进。
