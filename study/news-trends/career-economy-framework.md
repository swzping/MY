# 职业与经济方向判断框架

## 一句话框架

看到一条新闻或技术更新时，不只问“它火不火”，而是问：它会改变谁的工作、谁的收入、谁的成本、谁的机会。

## 判断层级

### 1. 事实层

先记录发生了什么。

- 谁发布或推动了这件事？
- 时间、地点、规模和对象是什么？
- 有无数据、原文、产品、论文、财报或政策文件？
- 哪些部分是事实，哪些部分是媒体或个人解读？

### 2. 机制层

判断它为什么重要。

- 它降低了什么成本？
- 它提高了什么效率？
- 它替代了什么流程？
- 它创造了什么新需求？
- 它把价值从哪里转移到了哪里？

### 3. 职业层

判断它对个人职业的影响。

| 方向 | 观察问题 |
| --- | --- |
| 技能 | 我需要补工具使用、工程能力、行业知识，还是表达判断能力？ |
| 岗位 | 哪些岗位会被增强，哪些岗位会被压缩？ |
| 竞争 | 入门门槛是降低了，还是高阶门槛提高了？ |
| 迁移 | 我现在的能力能迁移到哪些新场景？ |
| 风险 | 哪些工作内容会变成低价值、可自动化、可外包？ |

### 4. 行业层

判断它对行业格局的影响。

- 受益方：谁的效率、收入或议价能力提高？
- 受损方：谁的成本、流量或利润被挤压？
- 关键环节：价值集中在模型、数据、应用、渠道、硬件，还是服务？
- 进入门槛：是技术门槛、资金门槛、数据门槛、牌照门槛，还是场景门槛？

### 5. 经济层

判断它对经济方向的影响。

- 收入：会不会影响工资、就业数量或工作稳定性？
- 消费：会不会改变用户愿意花钱的地方？
- 投资：会不会影响资本流向、估值和企业扩张？
- 资产：会不会影响房产、股票、债券、商品或现金的相对吸引力？
- 周期：这是顺周期机会，还是逆周期机会？

## 时间尺度

| 时间 | 判断重点 | 典型行动 |
| --- | --- | --- |
| 短期，1 到 3 个月 | 热点、情绪、产品试用、信息差 | 观察、试用、记录案例 |
| 中期，3 到 12 个月 | 岗位变化、工具普及、企业采用 | 学习技能、做项目、调整简历 |
| 长期，1 到 3 年 | 行业结构、职业路径、资产配置 | 选择赛道、积累作品、建立判断模型 |

## 个人行动清单

每条重要信息最后都落到行动上。

- 继续观察：信息重要，但证据不足。
- 立即试用：工具或技术已经可用，值得上手。
- 深入学习：它影响未来岗位要求，需要系统补课。
- 记录案例：适合放进作品集、面试故事或行业分析。
- 暂不跟进：热度高但与个人方向关系弱。

## 评分模板

可以给每条信息打 1 到 5 分：

| 维度 | 分数 | 说明 |
| --- | --- | --- |
| 可信度 |  | 来源是否可靠，证据是否充分 |
| 影响范围 |  | 影响个人、岗位、行业还是宏观经济 |
| 持续时间 |  | 是短期热点还是长期趋势 |
| 可行动性 |  | 我是否能试用、学习、转化为项目或判断 |
| 与我相关度 |  | 是否影响我的职业、收入、技能和选择 |

总分不重要，重要的是迫使自己分开判断“热度”和“价值”。
