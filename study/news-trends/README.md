# 新闻、技术与趋势判断

这个目录用来区分不同类型的信息，并把日常新闻沉淀成职业方向、经济发展方向和学习重点的判断。

## 使用目标

- 区分 AI 圈新闻、技术更新、社会热点、行业热点和经济热点。
- 判断一条信息是短期噪音、阶段性变化，还是长期趋势。
- 从信息中提炼对职业选择、技能学习、行业机会和经济周期的启发。

## 快速记录模板

```markdown
## YYYY-MM-DD 标题

来源：

分类：

- AI 圈新闻 / 技术更新 / 社会热点 / 行业热点 / 经济热点

一句话摘要：

影响范围：

- 个人技能：
- 职业岗位：
- 行业格局：
- 宏观经济：

我的判断：

- 短期：
- 中期：
- 长期：

后续行动：

- 
```

## 判断原则

- 先分类，再判断，不急着下结论。
- 先看事实，再看解读，最后记录自己的判断。
- 把“热闹”与“结构性变化”分开。
- 每次只提炼 1 到 3 个后续行动，避免信息过载。
