# 测试规划工作流程

## 必做事项
- 在编写任何功能代码前，必须创建 `TEST_PLAN.md`
- 每个PR必须包含测试规划文档

## 测试规划模板
```markdown
## 功能描述
[简述要实现的功能]

## 测试场景
1. [核心路径] - 示例：用户登录成功流程
2. [边界情况] - 示例：密码错误3次后的锁定机制
3. [异常处理] - 示例：网络中断时的用户提示

## 验收标准
✅ 所有正向路径测试通过
✅ 100%核心路径覆盖率
✅ 异常场景有明确用户提示

## 执行计划
1. [ ] 创建测试用例文档
2. [ ] 搭建测试环境
3. [ ] 执行测试并记录结果
```

## 实施步骤
1. 在项目根目录创建 `TEST_PLAN.md` 模板文件
2. 将测试规划要求写入 `cto.md` 技术规范
3. 在团队文档中添加执行指南
