# 生鲜 SaaS 产品需求文档 (PRD) 专家

此技能基于生鲜行业最佳实践（如美团优选、叮咚买菜、SaaS WMS系统）构建，旨在帮助用户编写高质量、符合业务实际的生鲜/供应链 SaaS 产品需求文档。

## 为什么生鲜 SaaS PRD 很难写？

生鲜行业的特殊性在于**"物理世界的非标准化"**与**"数字世界的标准化"**之间的冲突。
通用 PRD 模板通常会忽略以下致命细节，导致系统上线即失败：
1.  **非标品（Catch Weight）**：下单 5kg，实发 4.8kg 或 5.2kg，如何结算？库存怎么扣？
2.  **多单位换算**：采购用"筐"，库存用"公斤"，销售用"份"。
3.  **高损耗**：入库 100 个，烂了 5 个，怎么报损？毛利怎么算？
4.  **高频变价**：早上 5 元/斤，晚上 3 元/斤，结算按哪个算？

## 核心检查清单 (Golden Patterns)

在编写 PRD 时，必须强制检查以下业务逻辑：

### 1. 商品与单位管理 (Item Master)
- [ ] **多单位支持**：必须定义 `基础单位` (如: kg) 和 `辅助单位` (如: 箱、筐、包)。
- [ ] **转换率**：固定转换率 (1箱=10kg) vs 浮动转换率 (抄码/称重)。
- [ ] **保质期管理**：入库必须录入生产日期/到期日，支持 FEFO (先到期先出) 逻辑。

### 2. 采购与入库 (Procurement & Inbound)
- [ ] **实收 ≠ 实订**：允许允许收货数量上下浮动（例如 ±10%）。
- [ ] **去皮/扣重**：收货时必须有扣除皮重（筐重）的逻辑。
- [ ] **批次管理**：每一批入库必须生成唯一批次号，用于溯源和成本核算。

### 3. 销售与出库 (Sales & Outbound)
- [ ] **库存分配策略**：下单时是`预占库存`还是`实扣库存`？(建议：下单预占，发货实扣)。
- [ ] **缺货处理**：捡货时发现缺货怎么办？(部分发货/整单取消/替代品)。
- [ ] **波次捡货**：针对高频生鲜，支持按线路/区域合并捡货，再进行二分播种。

### 4. 财务与核算 (Finance)
- [ ] **加权平均成本**：由于每日进价波动大，推荐使用移动加权平均法计算成本。
- [ ] **日结/周结**：支持不同供应商的结算周期配置。

## 常见反模式 (Anti-Patterns) - 避免这样做！

*   ❌ **错误**：把生鲜当标品设计，认为 "库存 = 入库 - 出库"。
    *   ✅ **正确**：库存 = 入库 - 出库 - **损耗** - **盘点差异**。
*   ❌ **错误**：设计"完美"的负库存控制，不允许负库存。
    *   ✅ **正确**：允许**暂时性负库存**。早市发货速度快于系统录入，先发货后补单是常态。
*   ❌ **错误**：忽略移动端场景。
    *   ✅ **正确**：仓库人员在冷库作业，必须设计 PDA/手机端界面，且要考虑弱网环境。

## 生鲜 SaaS PRD 推荐模板

### 1. 文档基础信息
- **项目背景**：解决什么供应链痛点？（如：降低损耗、提高人效）
- **核心指标**：期望将损耗率降低至多少？库存周转天数优化至多少？

### 2. 角色与流程图 (Business Process)
- **泳道图**：采购员 -> 供应商 -> 库管员 -> 分拣员 -> 司机 -> 客户。
- **状态机**：订单状态流转（待审核 -> 待分拣 -> 分拣中 -> 已称重 -> 待发运 -> 已签收）。

### 3. 功能详细需求 (Functional Requirements)

#### 3.1 商品中心
- 字段定义：SKU编码、品名、规格、皮重、保质期天数、存储温层（冷冻/冷藏/常温）。

#### 3.2 采购入库
- 功能：采购单创建、收货录入（支持连接蓝牙电子秤）、质检（拍照留痕）。
- **关键逻辑**：实收数量 > 采购数量时的审批流程。

#### 3.3 库存管理
- 功能：库位管理、盘点（日盘/周盘/动销盘）、报损（自然损耗/人为损坏）、调拨。

#### 3.4 销售出库
- 功能：智能排线（TMS集成）、波次生成、打印标签、发货复核。

### 4. 非功能性需求 (NFR)
- **并发性**：早市抢单高峰期的系统稳定性（如：秒杀场景）。
- **硬件集成**：必须支持电子秤、蓝牙打印机、PDA 扫码枪。
- **离线能力**：冷库内无信号时的断网操作支持。

## AI 辅助指令
- 当你写 PRD 时，请主动询问用户："您的业务是统配（中央仓发货）还是直配（供应商直发）？"
- 询问："是否需要支持‘以销定采’（预售）模式？"
