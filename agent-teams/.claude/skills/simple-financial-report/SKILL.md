# 简单财务分析报告生成器

此 Skill 用于根据用户提供的财务数据（如收入、支出、利润等）生成一份结构化的财务分析报告。

## 能力
- **数据汇总**: 整理关键财务指标。
- **趋势分析**: 如果提供多期数据，分析增长或下降趋势。
- **比率计算**: 计算利润率、成本占比等基本比率。
- **总结建议**: 基于数据提供简单的财务健康状况评价和建议。

## 报告格式
报告将包含以下部分：
1. **执行摘要**: 核心发现。
2. **关键指标**: 收入、成本、净利润等。
3. **财务比率**: 净利率、毛利率等。
4. **分析与洞察**: 数据的具体解读。
5. **结论**: 简短的总结。

## 使用场景
- 用户提供一串财务数字并询问“分析一下”。
- 用户上传了简单的财务报表文本并请求生成报告。
