# C端可变现小工具 - 设计文档

## 项目概述

根据用户要求，批量开发面向C端普通消费者的可变现小工具，覆盖四个行业方向，采用**单工具独立变现+批量快速试错**策略。每个工具控制在1-2周开发MVP版本，快速上线验证需求，验证成功再迭代。

### 核心策略
- 目标用户：C端普通消费者
- 开发模式：每个工具独立，MVP最小可行产品，快速上线
- 变现方式：支持一次性购买、订阅制、广告、CPS佣金等多种模式
- 技术要求：根据cto.md规范，Claude负责规划，编码任务委派给Gemini前端开发

## 工具列表与需求规格

### 一、金融理财投资方向（3个工具）

#### 1. 基金定投智能计算器&回测工具
**痛点**：基金定投用户对比不同策略（定投频率、止盈条件）很困难，网上计算器功能简单无法回测历史。
**核心功能（MVP）**：
- 输入基金代码、定投金额、开始时间
- 选择定投频率（日/周/双周/月）
- 设置止盈条件（收益率%/固定金额）
- 回测历史收益，展示累计收益、年化收益率对比不同策略
- 输出可视化收益曲线图
**非MVP（后续再加）**：定投提醒、组合管理
**变现模式**：一次性付费 19-29 元
**开发难度**：低
**数据来源**：免费基金API（东方财富/天天基金公开接口）

#### 2. 港股/美股股息复利计算器
**痛点**：股息投资者很难计算复利滚存效果，受汇率、手续费、分红再投资影响复杂。
**核心功能（MVP）**：
- 输入股票代码、初始买入股数、买入价格
- 设置股息再投资/不再投资选项
- 设置汇率变化假设、手续费
- 计算N年后总股数、总市值、累计分红
- 可视化复利增长曲线
**变现模式**：一次性付费 19 元
**开发难度**：低
**数据来源**：新浪财经/雪球API

#### 3. 个人ETF投资组合再平衡工具
**痛点**：做资产配置（如股债60/40）需要定期再平衡，手动计算买卖金额麻烦。
**核心功能（MVP）**：
- 用户设置目标配置比例（如股票60%/债券40%）
- 输入当前各ETF持仓和价格
- 自动计算需要买卖金额/份额，导出操作清单
- 记录历史再平衡操作
**变现模式**：一次性付费 39 元 或 订阅 5元/月
**开发难度**：中
**数据来源**：免费行情API

### 二、电商卖家工具方向（3个工具）

#### 4. 拼多多选品关键词挖掘工具
**痛点**：拼多多卖家找蓝海词需要查询搜索量、竞争度，官方工具贵。
**核心功能（MVP）**：
- 输入核心词，批量扩展相关关键词
- 查询每个关键词搜索量、商品数量
- 计算竞争度分数，排序筛选蓝海词
- 导出Excel关键词表
**变现模式**：一次性付费 29-49 元 或 订阅 10元/月
**开发难度**：低

#### 5. 电商标题智能生成工具
**痛点**：新手卖家不会写标题，不知道哪些关键词有流量。
**核心功能（MVP）**：
- 输入产品核心词
- 自动抓取同类目top商品标题
- 统计高频关键词，组合出高权重标题
- 支持生成多个不同版本供测试
**变现模式**：一次性付费 29 元
**开发难度**：低

#### 6. 1688一键找同款比价工具
**痛点**：拼多多卖家去1688找货源，同款多家价格差异大，手动找效率低。
**核心功能（MVP）**：
- 粘贴拼多多/淘宝商品链接
- 自动搜索1688同款商品
- 按价格、销量、发货地排序
- 展示价格对比表
**变现模式**：一次性付费 39 元
**开发难度**：中

---

### 三、内容创作/自媒体工具方向（3个工具）

#### 7. 短视频口播稿生成器
**痛点**：口播类短视频创作者每天写文案费时间。
**核心功能（MVP）**：
- 输入视频主题/关键词
- 选择视频时长（15s/30s/60s）
- AI生成完整口播稿 + 分镜提示
- 支持不同风格（干货/故事/干货）
**变现模式**：订阅 9元/月 或 一次性 39元
**开发难度**：低（基于OpenAI/Anthropic API）

#### 8. 批量字幕生成&关键词打标工具
**痛点**：UP主/短视频作者打字幕、加标签费时费力。
**核心功能（MVP）**：
- 上传视频/音频文件
- 自动转文字字幕
- AI提取核心关键词用于标签推荐
- 导出srt字幕文件
**变现模式**：按条数付费 或 月卡 12元/月
**开发难度**：中
**依赖**：OpenAI Whisper 或 第三方ASR API

#### 9. 小红书标题多版本生成工具
**痛点**：小红书标题决定点击率，需要多个版本测试。
**核心功能（MVP）**：
- 输入文章主题/核心关键词
- 生成10个不同风格标题：悬念型、干货型、福利型、提问型等
- 标注每个标题的类型特点
**变现模式**：一次性付费 19 元
**开发难度**：低（基于大模型API）

### 四、生活效率工具方向（3个工具）

#### 10. 网购历史价格追踪浏览器插件
**痛点**：电商大促很多先涨后降，消费者难辨真假低价。
**核心功能（MVP）**：
- Chrome浏览器插件
- 在商品页展示历史价格曲线图
- 提醒当前价格是否为历史低价
- 支持淘宝、京东、拼多多
**变现模式**：基础功能免费+广告，无广告高级版一次性 15 元
**开发难度**：中

#### 11. 外卖红包自动查找&领取工具
**痛点**：每次点外卖都要去各个群找红包链接，很麻烦。
**核心功能（MVP）**：
- 一键查询当前平台（美团/饿了么）可用红包
- 跳转领取页面
- 支持查询大额优惠券
**变现模式**：CPS佣金，每单分成
**开发难度**：低

#### 12. 健身计划自动生成器
**痛点**：健身房新手不会做计划，买私教贵，网上计划千人一面。
**核心功能（MVP）**：
- 输入身高体重、训练年限、目标（增肌/减脂/塑形）
- 输入可用器材（健身房/居家无器械）
- 生成每周训练计划，每个动作带图解说明
- 分部位安排，推荐组数次数
**变现模式**：一次性付费 29 元
**开发难度**：低

## 技术架构设计

### 整体架构
每个工具独立开发，可独立部署：
- 前端：HTML/CSS/JavaScript，使用Tailwind CSS 做样式
- 每个工具一个独立html文件（或简单单页应用）
- 数据：大部分依赖公开API，简单数据存在localStorage
- 支付：接入第三方支付（如微信支付/支付宝/独立站用Stripe）

### 技术栈选择
- 样式：Tailwind CSS CDN（无需构建，快速开发）
- JS：原生JS + 少量常用库（Chart.js做图表）
- 部署：可部署到Vercel/Netlify，或打包成EXE桌面端

### 开发顺序建议（优先级从高到低）
1. 低开发难度先做：
   - 小红书标题生成工具（内容方向，难度低）
   - 短视频口播稿生成器（内容方向，难度低）
   - 基金定投计算器（金融方向，难度低）
   - 股息复利计算器（金融方向，难度低）
   - 健身计划自动生成器（生活方向，难度低）
   - 外卖红包工具（生活方向，难度低）
2. 中等开发难度后做：
   - 拼多多关键词挖掘（电商方向，难度低-中）
   - 电商标题生成（电商方向，难度低）
   - ETF再平衡工具（金融方向，难度中）
   - 字幕关键词工具（内容方向，难度中）
   - 价格追踪插件（生活方向，难度中）
   - 1688找同款（电商方向，难度中）

## 风险与应对

1. **API失效风险**：公开API可能会变，应对：使用多个数据源备用，发现问题快速修复
2. **需求验证风险**：不是所有工具都有人买，应对：MVP快速开发快速上线，数据说话，不恋战
3. **维护成本**：12个工具分开维护，应对：保持代码简单，每个工具独立，好维护
