# 财务发票助手 - 发票查重验真+信息提取工具 - 实现规划

## 产品定位

**痛点：** 财务/会计/行政人员日常处理报销发票时：
1. 需要检查发票是否重复报销 → 人工核对非常麻烦，容易出错，给公司造成损失
2. 需要手动录入发票信息（发票号码、日期、金额、开票方）到Excel或财务软件 → 大量重复劳动，效率低下
3. 需要整理报销清单导出给财务软件批量导入 → 格式不对还要调整

**用户：** 中小企业财务、会计、行政报销人员
**付费意愿：** ⭐⭐⭐⭐⭐ 很高（避免财务风险+节省大量时间，公司愿意买单）
**开发难度：** ⭐⭐ 低（MVP快速落地）
**市场空间：** 千万级财务从业人员，痛点普遍存在

## 功能规划 MVP

### 核心功能
1. **发票图片上传/OCR识别** - 上传发票图片，自动提取关键信息
   - 发票号码
   - 开票日期
   - 总金额
   - 开票方名称
   - 税额

2. **自动查重提醒** - 识别后自动比对已存档发票号码，发现重复立即红框提醒
   - 绿色：新发票，未报销
   - 红色：重复发票，已报销过

3. **发票档案管理** - 本地保存已验过的发票清单
   - 表格显示所有已验发票
   - 支持手动删除错误录入
   - 支持手动新增发票（拍照不好用的时候）

4. **导出Excel/CSV** - 整理好的发票清单可以导出，方便导入财务软件做账

5. **数据本地存储** - 所有发票数据存在用户浏览器localStorage，不涉及隐私数据上传到第三方服务器（除了OCR识别API调用）

### 可选扩展（后续可加）
- 扫码录入发票二维码（直接读取信息更准确）
- 对接国税发票查验API验证发票真伪
- 支持批量上传多张发票
- 云端同步备份（需要账号系统）

## 技术架构

**MVP方案：纯前端HTML + JavaScript**
- HTML + 原生JavaScript
- Tailwind CSS via CDN
- OpenAI GPT-4 Vision API 做OCR发票识别（比纯OCR识别更准确，能理解发票结构）
- 用户提供自己的OpenAI API Key，存在本地
- localStorage存储发票档案
- 导出CSV功能

**优势：**
- 开发快，1天就能做完MVP
- 纯静态，部署免费
- 隐私性好，API Key本地存储，发票数据本地存储
- 用户按自己API调用量付费，我们卖工具收一次费，没有服务器成本
