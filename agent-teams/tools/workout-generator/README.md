# 健身计划自动生成器

输入你的健身目标、训练水平、可用器械，AI生成个性化的每周健身计划。

## 功能特点

- 支持多种健身目标：减脂/增肌/力量/耐力/保持健康
- 适配不同训练水平：新手/中级/高级
- 可选每周训练天数：3-6天
- 支持健身房器械、哑铃、无器械等多种配置
- API Key本地存储，隐私安全
- 点击任意段落一键复制
- 纯静态页面，无需后端

## 使用方法

1. 输入OpenAI API Key
2. 选择健身目标和你的训练水平
3. 选择每周训练天数和性别
4. 勾选你可用的健身器械
5. 填写额外要求（可选）
6. 点击生成，获取你的个性化计划

## 技术

- OpenAI GPT API
- 纯前端HTML + JavaScript
- localStorage本地存储
- Tailwind CSS via CDN
