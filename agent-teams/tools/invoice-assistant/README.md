# 财务发票助手 - 发票查重验真+信息提取

财务会计报销工作神器，上传发票图片AI自动提取信息，自动查重提醒，避免重复报销，导出CSV直接导入财务软件。

## 功能特点

- AI自动识别发票信息（发票号码、开票日期、金额、税额、开票方）
- 自动查重提醒，发现重复报销立即警告
- 本地保存发票档案，随时查看管理
- 支持多张图片批量识别
- 识别结果可手工编辑修正
- 导出CSV格式，直接导入财务软件
- API Key本地存储，发票数据本地存储，隐私安全
- 纯网页，无需下载安装，打开即用

## 使用方法

1. 输入你的OpenAI API Key（使用GPT-4 Vision进行OCR识别）
2. 拖放或选择发票图片上传，支持多张
3. 点击"开始识别所有图片"
4. 核对识别结果，如果有误可以手工修改
5. 确认保存，系统自动检查发票号码是否重复
6. 全部识别完后，导出CSV文件

## 技术说明

- 使用OpenAI GPT-4o-mini Vision API进行发票识别
- 纯前端HTML + JavaScript，无需后端
- 所有数据存储在你的浏览器本地
- API调用费用由你的OpenAI账号直接支付，本工具不收取任何API费用

## 费用估算

- 识别一张发票大约消耗 1k-2k tokens
- 按GPT-4o-mini价格，每张发票大约 ¥0.01-0.02 人民币
- 成本非常低，远低于人工录入成本

## 适用场景

- 中小企业财务人员处理报销
- 行政人员整理发票
- 需要批量导入到财务软件，避免手工录入
- 需要防范重复报销风险
