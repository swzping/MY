# ETF投资组合再平衡工具

帮助投资者计算ETF投资组合再平衡时需要买卖多少，清晰输出操作清单。

## 功能特点

- 可灵活添加多个ETF配置
- 设置每个ETF的目标配置比例
- 输入总投资金额
- 自动计算每个ETF需要买入/卖出多少金额
- 表格清晰显示操作清单

## 使用方法

1. 添加ETF行，输入代码/名称和目标比例
2. 输入总投资金额
3. 点击计算，查看操作清单
4. 根据计算结果进行再平衡操作

## 说明

- 首次再平衡：总投资金额就是你准备投入的总金额
- 定期再平衡：输入当前组合总市值，工具会计算需要调整的金额
- 总比例请调整到接近100%

## 技术

- 纯前端HTML + JavaScript
- 无需后端，本地计算
- Tailwind CSS via CDN
