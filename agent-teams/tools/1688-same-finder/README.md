# 1688找同款比价工具

帮助拼多多卖家整理1688供应商信息，对比不同供应商的价格和利润，方便找货源。

## 功能特点

- 手动添加多个供应商
- 自动计算每件利润
- 表格清晰对比
- 数据保存在浏览器本地
- 导出CSV方便后续分析

## 使用方法

1. 输入拼多多商品名称和售价
2. 逐个添加找到的供应商信息
3. 工具自动计算利润
4. 可以导出CSV保存

## 说明

MVP版本：手动添加供应商信息，适合小批量找货。后续可增加搜索API自动查找。

## 技术

- 纯前端HTML + JavaScript
- localStorage本地存储
- Tailwind CSS via CDN
