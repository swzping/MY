# 网购历史价格追踪工具

手动记录网购商品价格，追踪价格走势，查看历史最低价，设置目标价格提醒。

## 功能特点

- 添加商品并记录当前价格
- 支持淘宝/京东/拼多多多平台
- 折线图显示价格走势
- 自动计算历史最低价
- 设置目标价格提醒
- 数据保存在浏览器本地
- 可点击打开商品原链接

## 使用方法

1. 输入商品名称、当前价格
2. 选择平台，可粘贴商品链接
3. 可设置目标价格（低于此价提醒）
4. 点击"添加/更新价格"
5. 点击"查看走势"显示价格走势图

## 说明

MVP版本：手动记录价格。适合追踪大件商品价格变化，等待降价入手。

## 技术

- 纯前端HTML + JavaScript
- Chart.js 绘制价格走势图
- localStorage本地存储
- Tailwind CSS via CDN
