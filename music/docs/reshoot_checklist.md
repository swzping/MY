# 《庙堂之外_守望》古装园林补拍清单

目标：补齐真人剧情 MV 所需素材，让剪映成片有抖音式“人脸钩子、情绪变化、画面丰富度”。

## 拍摄设置

- [ ] 手机竖屏 `9:16`，不要横屏后裁。
- [ ] 优先 `4K 30fps`；空间不够用 `1080p 30fps`。
- [ ] 使用后置镜头，主唱镜头尽量固定机位或轻微推进。
- [ ] 每条镜头开头和结尾多留 1 秒。
- [ ] 演唱镜头用原歌外放或耳机辅助对口型。
- [ ] 古装颜色优先黑、白、深红、墨绿、藏蓝，避免荧光色和太花的纹样。
- [ ] 避免现代路牌、垃圾桶、游客、车辆、空调外机入镜。

## 必拍演唱镜头

- [ ] `SING_001_front_close_full.mov` 正脸近景，完整唱一遍。
- [ ] `SING_002_45_medium_full.mov` 45 度中景，完整唱一遍。
- [ ] `SING_003_chorus_close_take1.mov` 副歌强情绪近景，完整副歌。
- [ ] `SING_004_chorus_close_take2.mov` 副歌强情绪近景，备用一条。
- [ ] `SING_005_profile_detail_hook.mov` 侧脸或半脸，唱最抓人的一句。

## 必拍剧情镜头

- [ ] `STORY_001_corridor_back_walk.mov` 长廊背影向前走。
- [ ] `STORY_002_gate_stand_back.mov` 门洞中央背影站定。
- [ ] `STORY_003_turn_head.mov` 站在廊下慢慢回头。
- [ ] `STORY_004_look_up.mov` 抬头看灯、檐角或天空。
- [ ] `STORY_005_stop_steps.mov` 走路后停步。
- [ ] `STORY_006_leave_frame.mov` 从画面侧边离开。
- [ ] `STORY_007_hand_railing.mov` 手扶栏杆或门框。
- [ ] `STORY_008_sleeve_detail.mov` 衣袖、手部、配饰细节。
- [ ] `STORY_009_push_door.mov` 推门或经过门洞。
- [ ] `STORY_010_shadow_walk.mov` 地面影子或侧影走动。

## 情绪空镜

- [ ] `BROLL_001_roof_eaves.mov` 瓦檐或屋顶。
- [ ] `BROLL_002_lantern.mov` 灯、烛、暖色光源。
- [ ] `BROLL_003_window_grid.mov` 窗格或门格。
- [ ] `BROLL_004_stone_steps.mov` 石阶。
- [ ] `BROLL_005_tree_shadow.mov` 树影。
- [ ] `BROLL_006_water_reflection.mov` 水面或倒影。
- [ ] `BROLL_007_empty_corridor.mov` 无人长廊。
- [ ] `BROLL_008_gate_detail.mov` 门环、门缝、墙面纹理。

## 现场检查

- [ ] 人脸没有严重过暗。
- [ ] 正脸演唱口型能看清。
- [ ] 每条素材无明显抖动、失焦或突然遮挡。
- [ ] 背景没有明显现代元素。
- [ ] 至少有 4 条可用演唱镜头、20 条可用剧情/空镜。
