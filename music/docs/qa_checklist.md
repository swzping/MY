# 《庙堂之外_守望》成片验收清单

## 完整 MV

- [ ] 文件为竖屏 `1080x1920`，无黑边、无横屏裁切问题。
- [ ] 时长约 `58.05s`，音频完整无静音、无爆音。
- [ ] 前 3 秒有真人脸、回头、门洞背影或强动作钩子。
- [ ] 主歌画面克制，副歌画面明显更强。
- [ ] 结尾有余韵，不突然断掉。

## 口型

- [ ] 正脸演唱镜头与人声基本对齐。
- [ ] 副歌金句没有明显口型错位。
- [ ] 口型对不上的正脸镜头只作为短闪或不用。
- [ ] 演唱镜头不被字幕挡住嘴。

## 字幕

- [ ] 歌词已经人工校对。
- [ ] 字幕出现时间不早不晚。
- [ ] 手机屏幕上能看清。
- [ ] 字幕没有遮住脸、嘴和关键手部动作。
- [ ] 副歌重点句有更强视觉表现，但不花乱。

## 画面

- [ ] 古装、园林、灯光、调色风格统一。
- [ ] 人脸不过暗，眼神和表情能看清。
- [ ] 没有明显现代元素穿帮。
- [ ] 没有失焦、严重抖动、闪帧或素材缺失。
- [ ] 抽象 MV 只作为补位或叠化，不喧宾夺主。

## 短版

- [ ] 15 秒高潮版前三秒有脸或强动作。
- [ ] 15 秒版能直接听到最抓人的一句。
- [ ] 30 秒剧情版包含钩子、情绪铺垫和副歌释放。
- [ ] 两个短版不依赖完整 MV 也能看懂情绪。
