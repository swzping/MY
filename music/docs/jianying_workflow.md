# 《庙堂之外_守望》剪映执行流程

## 1. 新建项目

1. 新建剪映项目，画幅选 `9:16`。
2. 导入音频：`/Users/edy/Documents/庙堂之外_守望.m4a`。
3. 导入精选素材：`video/selects/`。
4. 导入备用抽象 MV：`exports/庙堂之外_守望_mv.mp4`，只作为补位、转场或背景叠化使用。

## 2. 整理轨道

- 主视频轨：演唱镜头和关键剧情镜头。
- 覆盖轨 1：空镜、细节、抽象 MV 叠化。
- 覆盖轨 2：标题、重点词、闪白、光效。
- 字幕轨：逐句歌词。
- 音频轨：锁定原曲，避免误移动。

## 3. 粗剪时间线

| 时间 | 主画面 | 备用补位 |
|---|---|---|
| 00:00-00:03 | 副歌强表情/回头/门洞背影 | 抽象 MV 标题段 |
| 00:03-00:07 | 灯、瓦檐、无人长廊 | 抽象 MV 宫墙段 |
| 00:07-00:24 | 45 度演唱、背影、手部、窗格 | 抽象 MV 窗影段 |
| 00:24-00:34 | 停步、回头、抬头、推门 | 抽象 MV 光线增强段 |
| 00:34-00:50 | 正脸副歌演唱 + 剧情动作 | 抽象 MV “我仍在此处守望”段 |
| 00:50-00:58 | 背影远去、灯暗、水面 | 抽象 MV 结尾段 |

## 4. 动态歌词

1. 先用剪映“识别歌词/字幕”生成初版。
2. 按 `lyrics/lyrics_template.md` 校对歌词。
3. 按 `lyrics/subtitle_timing_sheet.csv` 调整每句进出点。
4. 主歌字幕小而克制；副歌字幕大一些。
5. 字幕避开脸、嘴、手部动作，优先放画面下方 22%-28%。

## 5. 抖音感包装

- 开头 3 秒必须有主体，不要纯空镜。
- 标题只出现一次：`庙堂之外` / `守望`。
- 副歌重点词可以加粗、放大、金色描边或轻微闪白。
- 转场只用在段落切换：闪白、叠化、遮挡、动作衔接。
- 不要全程使用复杂特效，演唱表情要比特效更重要。

## 6. 调色

- 基调：低饱和、略高对比、暖灯冷影。
- 人脸不能压太暗，副歌要能看清眼神和嘴型。
- 园林空镜可稍微偏冷，灯/门洞光线可偏暖。
- 所有镜头统一一个调色方向，不要每条素材单独套不同滤镜。

## 7. 导出版本

### 完整 MV

- 文件名：`庙堂之外_守望_full_mv_v1.mp4`
- 分辨率：`1080x1920`
- 帧率：跟随素材，建议 `30fps`
- 位置：`exports/`

### 15 秒高潮版

- 文件名：`庙堂之外_守望_15s_hook_v1.mp4`
- 内容：副歌最强一句 + 人脸钩子 + 门洞/背影收束。
- 前三秒必须有脸或强动作。

### 30 秒剧情版

- 文件名：`庙堂之外_守望_30s_story_v1.mp4`
- 内容：钩子 + 主歌情绪 + 副歌释放。
- 能独立看懂“守望”的情绪线。

## 8. 发布前检查

- 完整 MV、15 秒、30 秒都能独立播放。
- 音画同步，演唱镜头口型没有明显错位。
- 字幕没有错字，也没有挡脸。
- 封面在手机缩略图里仍能看清标题和人物。
