# 《庙堂之外_守望》抖音感真人剧情 MV 项目

目标：制作一支 `9:16` 竖屏真人剧情 MV，并导出完整 MV、15 秒高潮版、30 秒剧情版。

## 当前状态

已完成：

- 抽象视觉完整占位版：`exports/庙堂之外_守望_mv.mp4`
- 15 秒占位短版：`exports/庙堂之外_守望_15s_hook_placeholder.mp4`
- 30 秒占位短版：`exports/庙堂之外_守望_30s_story_placeholder.mp4`
- 古装园林补拍清单：`docs/reshoot_checklist.md`
- 剪映执行流程：`docs/jianying_workflow.md`
- 分镜和短版方案：`docs/storyboard.md`
- 剪辑时间线：`docs/edit_timeline.csv`
- 字幕时间轴：`lyrics/subtitle_timing_sheet.csv`

待完成：

- 补拍真人古装园林素材。
- 校对正式歌词。
- 在剪映中用真人素材替换占位视觉，导出最终版本。

## 拍摄后放置

- 原始自拍视频：`video/raw/`
- 精选可用素材：`video/selects/`
- 封面照片：`video/selects/` 或单独新建 `cover/`

建议按 `docs/reshoot_checklist.md` 里的文件名拍摄和重命名，这样剪辑表可以直接对应素材。

## 剪辑入口

1. 先看 `docs/reshoot_checklist.md` 完成补拍。
2. 按 `docs/shot_selection_sheet.csv` 筛选素材。
3. 按 `docs/edit_timeline.csv` 搭建时间线。
4. 按 `lyrics/lyrics_template.md` 和 `lyrics/subtitle_timing_sheet.csv` 做动态字幕。
5. 按 `docs/qa_checklist.md` 验收。

## 备用素材

抽象版 `exports/庙堂之外_守望_mv.mp4` 可以作为：

- 无真人素材时的占位发布版本。
- 剪映中的背景叠化素材。
- 转场、字幕底图或结尾留白素材。
