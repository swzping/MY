# MY 工作区

这是一个个人多项目工作区，包含学习笔记、独立应用、脚本工具和素材资源。

## 一览

- `study/`：学习记录，包含 AI 工具、新闻趋势、术语与方法笔记。
- `mahjong-booking/`：麻将预约小程序。
- `study-site/`：学习主题站点。
- `pwa-studio-guardian-lab/`：PWA Studio 练习项目。
- `shouwang/`：守望智能体桌面工作台。
- `jizhang/`：记账应用。
- `health/`：健康应用。
- `Chinese-Classics/`：国学相关项目。
- `sub2api/`：Sub2API 平台项目。
- `agent-teams/`：智能体与技能集合。
- `my-codex-portable-kit/`：Codex 相关技能与便携包。
- `my-finance/`：金融与投放素材。
- `music/`：音乐视频制作资料。
- `mcp/`：MCP 相关工作区。
- `plugins/`：本地插件资源。
- `auto-task/`：自动化任务与脚本。

## 常用入口

- [学习记录](study/README.md)
- [学习术语表](study/ai-tools/glossary.md)
- [新闻与趋势记录](study/news-trends/README.md)

## 工作约定

- 各目录大多是独立项目，通常需要进入各自目录运行。
- 每个项目的启动方式、测试命令和依赖，以项目内的 `README.md`、`package.json`、`Dockerfile` 或脚本为准。
