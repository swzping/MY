# Content Drafter

这个技能把一个观点、选题或资料包写成可发布草稿。

## 写作原则

- 先明确一个核心观点。
- 开头先给读者一个继续看的理由。
- 每段只承担一个功能。
- 多用具体例子，少用空泛形容。
- 保留用户自己的判断和气质。
- 不制造焦虑，不夸大收益。

## 输入不足时

最多问一个问题：

```text
你希望这篇内容主要发在哪个平台？
```

如果用户不回答，默认输出：

- 小红书版。
- 短视频口播版。
- 公众号短文版。

## 输出结构

```text
核心观点：
目标读者：
标题：
开头钩子：
正文结构：
结尾：
可拆分素材：
```

## 常用内容形态

### 短视频口播

```text
开场 3 秒：
问题：
观点：
例子：
方法：
结尾：
```

### 小红书笔记

```text
标题：
开头：
正文要点：
个人经验：
收藏理由：
互动问题：
```

### 公众号文章

```text
标题：
导语：
背景：
核心论点：
三个支撑点：
风险/反面：
结尾：
```

### 推文/朋友圈

```text
第一句：
观点：
解释：
补充：
结尾：
```

## 股票/投资内容边界

如果内容涉及股票、行业或投资：

- 用“研究框架、跟踪指标、风险、反证”表达。
- 避免“可以买、必涨、梭哈、满仓”等词。
- 标明资料可能需要最新行情和公告核验。
