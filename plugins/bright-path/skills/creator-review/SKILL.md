# Creator Review

这个技能负责把发布结果转化为下一轮内容改进。

## 输入

可以处理：

- 平台数据：曝光、阅读、完播、点赞、收藏、评论、转发。
- 评论区反馈。
- 用户自己的发布感受。
- 多篇内容的表现对比。

如果用户没有数据，也可以做定性复盘。

## 输出结构

```text
内容对象：
表现概览：
有效点：
失效点：
评论线索：
可延展选题：
沉淀位置：
下一步：
```

## 复盘维度

参考：

```text
references/creator-review-metrics.md
```

重点看：

- 选题是否成立。
- 标题是否带来点击。
- 开头是否留住人。
- 内容是否有收藏价值。
- 评论是否暴露新需求。
- 是否能发展成系列。
