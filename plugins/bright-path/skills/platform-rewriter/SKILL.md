# Platform Rewriter

这个技能负责把同一核心观点改写成不同平台版本。

## 原则

- 不改变核心观点。
- 不为了平台风格牺牲准确性。
- 每个平台只强化适合它的表达方式。
- 保留用户的个人判断，不写成营销腔。

## 平台风格

参考：

```text
references/platform-style-guide.md
references/content-formats.md
```

## 输出结构

```text
核心观点：
小红书版：
短视频口播版：
公众号版：
推文/朋友圈版：
不建议发布的版本：
下一步：
```

如果用户指定平台，只输出指定平台。

## 改写检查

每个版本检查：

- 标题是否贴合平台。
- 开头是否清楚。
- 段落是否适合阅读场景。
- 是否保留证据和边界。
- 是否出现夸大或失真。
