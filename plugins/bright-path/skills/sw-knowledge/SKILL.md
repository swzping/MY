# SW Knowledge

这个技能把 `/Users/edy/Documents/SW` 当作本地知识库根目录，帮助用户从已有资料中检索证据、整理脉络、形成下一步研究行动。

## 知识库根目录

```text
/Users/edy/Documents/SW
```

## 适用场景

使用这个技能处理：

- 查询 SW 知识库里某个主题、公司、股票、行业、产品或项目。
- 基于 SW 的资料整理研究框架、备忘录、复盘或行动清单。
- 从输入流、原子知识、主题地图、综合输出中提炼线索。
- 对股票/项目资料做证据归纳、风险识别、待验证问题整理。

不要在没有读取资料的情况下声称“SW 里有/没有某内容”。如果检索不到，要明确说“在已检索范围内未找到”。

## 检索顺序

默认按这个顺序工作：

1. 用 `rg --files /Users/edy/Documents/SW` 了解相关文件位置。
2. 用 `rg "<关键词>" /Users/edy/Documents/SW` 搜索主题、公司、股票代码、项目名、行业词。
3. 优先读取这些目录中的命中文件：
   - `40-综合输出/研究备忘录`
   - `40-综合输出/趋势判断`
   - `30-主题地图`
   - `20-原子知识`
   - `10-输入流/概念雷达`
   - `10-输入流/日报`
   - `10-输入流/原始资料`
4. 如果是流程、分类、模板问题，再读取：
   - `90-系统/规则`
   - `90-系统/模板`
   - `90-系统/标签体系.md`

## 输出结构

根据问题选择最小结构。默认使用：

```text
检索范围：
找到的资料：
核心结论：
证据与来源：
不确定点：
下一步：
```

涉及股票或投资研究时，使用：

```text
研究对象：
资料事实：
已有判断：
我的推断：
主要风险：
待验证问题：
下一步研究：
```

涉及项目研究时，使用：

```text
项目主题：
已有资料：
核心脉络：
机会点：
阻碍点：
下一步：
```

## 引用规则

- 回答中要引用实际读取过的文件路径。
- 区分“文件中明确写到的内容”和“基于资料做出的推断”。
- 不要长篇复制原文，只摘取必要短句或用自己的话概括。
- 如果资料来自输入流，提醒用户它可能还没有被验证或沉淀。

## 股票研究边界

- 不直接给“买入、卖出、满仓、梭哈”等交易指令。
- 可以整理研究框架、风险、催化、反证、跟踪指标和待验证问题。
- 如果需要最新行情、公告、财报、监管或新闻，必须说明 SW 本地资料可能不是最新，并建议另行联网或调用行情数据工具核验。
- 输出里不要把个人笔记当作确定事实。

## 与 Bright Path 的配合

读取 SW 资料后，可以把结论交给 Bright Path 主流程，转化为：

- 下一步研究计划
- 每日/每周复盘
- 决策辅助表
- 项目推进清单
- 写作或研究备忘录草稿
