# Creator Workflow

这是 Bright Path 的网络博主工作流总入口。它帮助用户把已有知识资产转化为稳定内容输出，而不是临时憋标题。

## 定位

默认账号定位为混合型个人 IP：

```text
用 AI 工具、知识系统和研究方法，持续发现机会、整理判断、形成输出。
```

内容主轴：

- AI 工具、Agent、MCP、工作流。
- 知识管理、个人资料库、研究方法。
- 股票/项目/行业观察，但不直接给交易指令。
- 普通人如何用工具提高判断力和行动效率。

## 工作流

按用户所处阶段分流：

1. 找选题 -> 使用 `topic-selector`。
2. 写草稿 -> 使用 `content-drafter`。
3. 改平台版本 -> 使用 `platform-rewriter`。
4. 发布前检查 -> 本技能内完成。
5. 发布后复盘 -> 使用 `creator-review`。
6. 查询 SW 资料 -> 配合 `sw-knowledge`。
7. 查询 IMA 知识库 -> 配合 `ima-copilot`。

## 默认流程

如果用户没有指定阶段，按这个顺序推进：

```text
资料输入 -> 选题判断 -> 内容结构 -> 多平台改写 -> 发布检查 -> 数据复盘 -> 选题沉淀
```

## 输出结构

```text
当前阶段：
目标：
可用资料：
建议动作：
下一步：
```

如果用户要完整规划一轮内容生产，输出：

```text
本轮主题：
候选选题：
优先级：
内容形态：
平台分发：
发布前检查：
复盘方式：
下一步：
```

## 发布前检查

发布前至少检查：

- 标题是否具体。
- 开头是否能在 3 秒内说明价值。
- 是否有一个清晰观点。
- 例子是否来自真实资料或经验。
- 是否空泛、过度承诺或制造焦虑。
- 股票/投资内容是否避免直接交易指令。
- 是否有一个自然结尾：提问、收藏理由、下一篇预告或行动建议。

## 边界

- 不自动发布内容。
- 不编造平台数据。
- 不把 SW 输入流当作已验证事实。
- 投资相关内容只做研究表达、风险提示和待验证问题，不输出买卖指令。
