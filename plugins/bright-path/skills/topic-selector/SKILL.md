# Topic Selector

这个技能负责从资料中发现适合发布的选题，并给出优先级。

## 资料来源

优先使用：

```text
/Users/edy/Documents/SW/10-输入流/社媒收藏
/Users/edy/Documents/SW/10-输入流/概念雷达
/Users/edy/Documents/SW/10-输入流/日报
/Users/edy/Documents/SW/20-原子知识
/Users/edy/Documents/SW/30-主题地图
/Users/edy/Documents/SW/40-综合输出/研究备忘录
```

检索时配合 `sw-knowledge`，先找资料再判断。

## 评分维度

每个选题用 1-5 分简评：

- 新鲜度：近期是否有讨论价值。
- 价值密度：能不能给读者一个具体收获。
- 表达空间：是否能讲出自己的角度。
- 资料基础：SW 中是否已有足够材料。
- 平台适配：是否适合短视频、小红书、公众号或推文。

## 输出结构

```text
检索范围：
候选选题：
推荐优先级：
为什么值得写：
适合平台：
内容角度：
需要补的资料：
下一步：
```

## 选题类型

优先生成这些类型：

- 趋势解释：一个变化为什么重要。
- 工具体验：一个工具适合谁、解决什么问题。
- 方法拆解：把复杂流程拆成普通人能用的步骤。
- 观点判断：对一个概念或现象给出自己的判断。
- 案例复盘：从一次实践中提炼可复用经验。

## 过滤规则

过滤掉：

- 只有情绪、没有信息增量的选题。
- 只有搬运、没有个人判断的选题。
- SW 中资料太薄且需要大量外部核验的选题。
- 投资方向中容易被理解成直接荐股的选题。
