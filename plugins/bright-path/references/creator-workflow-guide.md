# 网络博主工作流指南

Bright Path 的创作者工作流面向混合型个人 IP：

```text
用 AI 工具、知识系统和研究方法，持续发现机会、整理判断、形成输出。
```

## 总流程

```text
资料输入 -> 选题判断 -> 内容结构 -> 多平台改写 -> 发布检查 -> 数据复盘 -> 选题沉淀
```

## 资料输入

优先从 SW 本地知识库读取：

```text
10-输入流/社媒收藏
10-输入流/概念雷达
10-输入流/日报
20-原子知识
30-主题地图
40-综合输出/研究备忘录
```

## 内容主轴

- AI 工具与工作流。
- Agent、MCP、Skill、自动化。
- 知识管理与个人研究系统。
- 投资/项目观察中的研究方法。
- 普通人如何用 AI 提高判断力。

## 一轮内容生产

```text
1. 从 SW 检索 10 个线索。
2. 筛成 3 个候选选题。
3. 选 1 个主选题写草稿。
4. 改写成 2-3 个平台版本。
5. 发布前检查标题、开头、证据、边界。
6. 发布后复盘数据和评论。
7. 把有效角度沉淀回 SW。
```

## 质量标准

一条内容至少要满足：

- 有一个清晰观点。
- 有一个具体场景。
- 有一个读者能拿走的东西。
- 有资料、案例或经验支撑。
- 有边界，不把推断包装成事实。
