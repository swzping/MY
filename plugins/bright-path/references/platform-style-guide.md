# 平台风格指南

## 小红书

- 标题具体、有场景、有收益点。
- 段落短，适合扫读。
- 多用“我怎么做”“普通人怎么用”“踩坑后发现”。
- 结尾给收藏理由或互动问题。

避免：

- 太像论文。
- 纯概念堆叠。
- 过度营销口吻。

## 短视频/视频号

- 前 3 秒说清问题或反差。
- 句子短，适合口播。
- 每 10-15 秒有一个推进。
- 结尾给一句可记住的判断。

避免：

- 长句。
- 开头铺垫太久。
- 只讲工具名，不讲场景。

## 公众号

- 适合完整论证。
- 可以讲背景、案例、推理和反面。
- 标题不必过度刺激，但要明确主题。
- 结尾适合沉淀方法论。

## 微博/X/朋友圈

- 第一句就是观点。
- 观点密度高。
- 可使用短段落连续推进。
- 适合观察、判断、金句和系列线索。

## 知识卡片

- 一个卡片只讲一个概念。
- 标题是概念名或判断句。
- 内容包含定义、例子、用法、误区。
