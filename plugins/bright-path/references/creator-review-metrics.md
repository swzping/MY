# 创作者复盘指标

## 基础指标

- 曝光/推荐量：平台是否愿意分发。
- 阅读/播放量：标题和封面是否有效。
- 完读/完播率：开头和节奏是否有效。
- 点赞：情绪共鸣或观点认同。
- 收藏：实用价值。
- 评论：讨论价值和需求线索。
- 转发：社交表达价值。

## 定性指标

- 是否有人问下一步。
- 是否有人补充案例。
- 是否有人质疑核心观点。
- 是否出现可以延展的新问题。
- 是否适合做系列。

## 复盘模板

```text
内容标题：
平台：
发布时间：
数据概览：
最有效的部分：
最弱的部分：
评论线索：
可延展选题：
下次调整：
沉淀到 SW：
```

## 判断规则

- 收藏高：方法、清单、工具、模板值得继续。
- 评论多：观点、争议、身份共鸣值得继续。
- 播放高但互动低：标题可能有效，内容价值不足。
- 数据低但评论质量高：小众深选题，可做系列慢慢养。
