# SW 本地知识库使用指南

Bright Path 的 `sw-knowledge` 技能会读取本机目录：

```text
/Users/edy/Documents/SW
```

## 当前知识库结构

常见目录：

```text
00-入口
10-输入流
20-原子知识
30-主题地图
40-综合输出
90-系统
```

## 建议检索入口

- `00-入口`：工作台、整理建议。
- `10-输入流`：日报、原始资料、概念雷达、社媒收藏，适合找线索。
- `20-原子知识`：产品项目、概念、人物组织、论文技术，适合找沉淀后的单点知识。
- `30-主题地图`：主题级脉络。
- `40-综合输出`：周报、研究备忘录、趋势判断，适合找阶段性结论。
- `90-系统`：规则、模板、标签体系。

## 推荐命令

查文件：

```bash
rg --files /Users/edy/Documents/SW
```

查关键词：

```bash
rg "关键词" /Users/edy/Documents/SW
```

限制 Markdown：

```bash
rg "关键词" /Users/edy/Documents/SW -g '*.md'
```

## 股票/项目资料整理原则

整理股票或项目资料时，优先分开：

- 资料事实
- 已有判断
- 个人推断
- 风险
- 反证
- 待验证问题
- 下一步研究动作

如果资料时间较旧，或需要实时行情、财报、公告、新闻，应明确提示需要另行核验。
